# Seaside Serenity

A static launch-preview website for a child-created fashion brand concept, translated from handwritten sketches into a polished first website build.

## Files
- `index.html` — homepage / brand landing page
- `about.html` — founder story and brand principles
- `collection.html` — first six product descriptions
- `styles.css` — shared site styling
- `script.js` — mobile navigation + footer year

## Publish
This site is static and GitHub Pages-friendly. No build step required.
