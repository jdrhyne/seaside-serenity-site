FAQ

Still safe, still parent-managed.

Is this live checkout yet?

Not yet. This is a real deployed site, but still a launch preview. Checkout should be added only after the final first-drop products and vendor are chosen.

Why show more categories than the first drop?

Because the sketch imagined a fuller world. The site now reflects that world visually, while the actual first release stays disciplined.

How is privacy handled?

Public story uses first name only. Parent-managed contact, payments, customer communication, and any future checkout remain under adult control.
